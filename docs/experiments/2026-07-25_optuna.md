# Phase 13 Optuna Nested Walk Forward Experiment

## 目的

Phase 11までのウォークフォワード評価を利用し、Outer Testをパラメータ選択へ使わないNested Walk ForwardでLightGBMのハイパーパラメータを探索する。未使用のOuter Testにより、既定モデルとTunedモデルを同じ期間で比較する。

## 実験条件

| 項目 | 条件 |
|---|---|
| Ticker | 7203.T |
| Period | 2y |
| 価格データ | 486件 |
| 学習データ | 435件 |
| Outer Fold | initial 100 / test 20 / step 20 |
| Inner Fold | initial 60 / test 20 / step 20 |
| Outer Fold数 | 16 |
| Trial数 | 各Outer Study 20、合計320 |
| Buy Threshold | 0.55 |
| Sampler | TPE、seed固定 |
| Objective | Inner Foldの平均Penalty付きSharpe Ratio |

## 探索空間

| Parameter | Range |
|---|---|
| `learning_rate` | 0.005～0.2、log scale |
| `num_leaves` | 15～127 |
| `max_depth` | 3～12 |
| `min_child_samples` | 5～100 |
| `feature_fraction` | 0.5～1.0 |
| `bagging_fraction` | 0.5～1.0 |
| `bagging_freq` | 1～10 |

`boosting_type=gbdt`、`objective=binary`、`random_state=42`、`n_estimators=100`、`n_jobs=1`は固定した。

## Nested評価

各Outer Foldの学習末尾1件をパージした後、そのOuter学習期間だけからInner Foldを作った。Inner Foldでも学習末尾1件をパージし、翌営業日Targetが検証開始日の価格を参照しないようにした。

Optunaの目的関数が受け取るのはInner Foldと価格データだけである。Outer Testの特徴量、Target、価格、指標はBest Parameter決定後まで使用しない。各Outer Foldに独立したStudyを用意し、Best Parameter決定後に同じOuter Testで既定モデルとTunedモデルを評価した。

Penaltyは以下のとおりである。

- Total Tradesが5未満: Inner Foldスコアから1.0を減算
- Sharpe RatioがNaNまたは無限値: そのFoldの寄与を-10.0
- Fold評価失敗: そのFoldの寄与を-10.0

## Best Parameter

将来利用候補はOuter Testの成績から選ばず、最も新しく最大の学習期間を持つOuter Fold 16のInner Studyから取得した。

```json
{
  "learning_rate": 0.07918764859922989,
  "num_leaves": 114,
  "max_depth": 3,
  "min_child_samples": 35,
  "feature_fraction": 0.5133616046084508,
  "bagging_fraction": 0.8919444877275278,
  "bagging_freq": 6
}
```

Best Inner Scoreは`0.7290906788`だった。この値はPenalty適用後のInner目的関数であり、Outer TestのSharpe Ratioではない。

## 最適化前後比較

数値は未使用Outer Test 16 Foldの平均である。

| Metric | Default | Tuned | Difference | Relative Change |
|---|---:|---:|---:|---:|
| Accuracy | 0.4844 | 0.4938 | +0.0094 | +1.94% |
| F1 | 0.4978 | 0.4624 | -0.0353 | -7.09% |
| ROC-AUC | 0.4987 | 0.5428 | +0.0441 | +8.84% |
| Total Return | -0.81% | -0.16% | +0.65 pp | 損失幅80.29%縮小 |
| Sharpe Ratio | -0.4253 | 0.7352 | +1.1606 | +272.87%相当 |

Sharpe Ratioは負から正へ符号が変わるため、相対変化率は直感的な「倍率」を表さない。主要な比較値は絶対差`+1.1606`とする。

## 考察

- Optunaの目的としたSharpe RatioのOuter平均は上昇した。
- AccuracyとROC-AUCも上昇したが、F1は低下した。
- Total Returnは損失幅が縮小したものの、平均は依然として負だった。
- Tunedモデルの平均Total Tradesは3.6875から2.5625へ減少し、Outer Testでも取引数が少なかった。
- Inner ScoreはFoldによって-1.0000～2.4745と大きく異なり、最適パラメータもFoldごとに変動した。
- 最適化対象へ近い指標が上昇しても、分類指標や収益性が一様に向上するわけではない。

## 限界

- 単一銘柄・単一の2年期間だけの結果であり、一般化できない。
- 20 Trialは探索空間に対して限定的である。
- Inner Fold数は初期Outer Foldほど少なく、目的関数の分散が大きい可能性がある。
- Fold間で学習期間が重複するため、各結果は独立ではない。
- 手数料、税金、スリッページを考慮していない。
- Outer Testを用いた候補選択は避けているが、将来の別期間での再検証が必要である。
