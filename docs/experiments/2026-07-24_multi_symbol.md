# Phase 12 Multi-Symbol Walk-Forward Experiment

## 実験目的

Phase 11で実装したexpanding window形式のウォークフォワード検証を複数銘柄へ同一条件で適用し、特徴量セットごとの分類性能、バックテスト結果、期間ごとのばらつきを確認する。銘柄を結合した学習ではなく、各銘柄を独立して評価した。

## 対象銘柄

- 7203.T
- 6758.T
- 9432.T
- 8306.T
- 8035.T

全5銘柄の取得と評価に成功し、失敗銘柄はなかった。

## 実験条件

| 項目 | 条件 |
|---|---|
| 実行日 | 2026-07-24 |
| 取得期間 | 2y |
| ウォークフォワード | expanding window |
| Initial Train Size | 100 |
| Test Size | 20 |
| Step Size | 20 |
| Buy Threshold | 0.55 |
| 特徴量セット | All 20 / Top 15 / Top 10 / Baseline 9 |
| Fold数 | 各銘柄16、合計80 |

各Foldで学習末尾1件を除外し、翌営業日の価格から作られる境界Targetを学習とGain順位決定へ含めていない。Top 15とTop 10は、そのFoldのパージ済み学習データだけで再選択した。バックテストは各Foldの最終予測日の翌取引日までに限定した。

## 安定性

Accuracy、F1、ROC-AUC、Total Return、Sharpe Ratioの標準偏差が小さいセットを数えた。

- Baseline 9: AccuracyとSharpe Ratioの標準偏差が最小
- Top 10: F1とROC-AUCの標準偏差が最小
- All 20: Total Returnの標準偏差が最小
- Top 15: 上記5指標では最小なし

したがって、選択した安定性指標ではTop 10とBaseline 9が同数であり、単独の「最も安定した特徴量セット」は決められなかった。銘柄別でも安定性の判定は異なった。

## 考察

- 全銘柄集約ではTop 10のAccuracy、F1、Total Return、Sharpe Ratioの平均が4セット中で最も高かった。
- ROC-AUC平均はAll 20が4セット中で最も高かった。
- 平均値が高いセットと標準偏差が小さいセットは指標によって異なった。
- 正のTotal ReturnとなったFoldはTop 10が48件で最も多かったが、32件は正ではなかった。
- 以上は観測したデータの記述であり、特徴量削減による因果的な改善や将来性能を証明するものではない。

## 限界

- 対象は日本株5銘柄だけであり、市場全体へ一般化できない。
- 単一の2年取得期間に限られ、異なる相場局面を十分に含むとは限らない。
- Fold同士はexpanding windowにより独立ではなく、学習期間が重複する。
- 取引手数料、税金、スリッページを考慮していない。
- ハイパーパラメータやBuy Thresholdは固定しており、他条件との比較ではない。
