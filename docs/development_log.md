## 発生した問題

- 制限された実行環境内では、PyPIとYahoo Financeの名前解決ができなかった。
- Apple標準Python 3.9のLibreSSL 2.8.3に対し、urllib3 v2の互換性警告が出た。
- 制限された実行環境内では、Streamlitがローカルポートをbindできなかった。
- Streamlitから任意のファイル変更監視を高速化するWatchdogの追加案内が出た。

## 原因

- 前者2件の通信問題とポート問題は、作業環境のネットワーク・ソケット制限によるものだった。
- urllib3警告はApple標準PythonがOpenSSLではなく古いLibreSSLでビルドされているためだった。
- Watchdogは必須依存ではなく、未導入時に表示される性能向上の案内だった。

## 解決方法

- 利用者の許可を得たネットワーク環境で依存関係と実データを取得した。
- Python 3.9環境向けに `urllib3==1.26.20` を固定し、警告が消えることを確認した。
- 許可された環境でStreamlitを起動し、ヘルスチェック後に正常終了した。
- Watchdogは機能に影響しないため、第1段階の必須依存には追加しなかった。
